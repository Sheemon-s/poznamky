1. Množiny (Set)
Čo je množina?
Množina (set) je dátová štruktúra určená na ukladanie unikátnych hodnôt.
Vlastnosti
  • Prvky sa neopakujú
  • Nemajú indexy
  • Poradie prvkov je náhodné
  • Môžu obsahovať rôzne dátové typy
  • Používajú sa keď potrebujeme odstrániť duplicity
  • Veľmi rýchlo zisťujú či sa prvok nachádza v množine
Vytvorenie
m = {1,2,3}
m = set()

# Ak sa hodnota opakuje:
{1,2,2,3} -> {1,2,3}
Operácie nad množinami
m1 = {1,2,3,4}
m2 = {3,4,5,6}

# Zjednotenie
print(m1 | m2)   # {1, 2, 3, 4, 5, 6}

# Prienik
print(m1 & m2)   # {3, 4}

# Rozdiel
print(m1 - m2)   # {1, 2}

# Vylučovacie zjednotenie (vyhodí prvky ktoré sú v obidvoch)
print(m1 ^ m2)   # {1, 2, 5, 6}

# Kontrola či je prvok v množine
print(3 in m1)  # True

# Podmnožina
print({1,2} <= m1)  # True
Najpoužívanejšie funkcie
mnozina = {5,4,3,2,1}

print(len(mnozina))     # 5
print(min(mnozina))     # 1
print(max(mnozina))     # 5
print(sorted(mnozina))  # [1, 2, 3, 4, 5]
print(list(mnozina))    # [1, 2, 3, 4, 5]
Najpoužívanejšie metódy
m = {1,2,3}

m.add(4)       # Pridá nový prvok do množiny
m.remove(2)    # Vymaže prvok. Ak tam nie je, vyhodí chybu
m.discard(10)  # Vymaže prvok. Ak tam nie je, neurobí nič
m.pop()        # Vymaže náhodný prvok a vráti ho
m.clear()      # Vymaže úplne celú množinu

print(m)
Kde sa používa?
  • Odstraňovanie duplicít
  • Porovnávanie skupín dát
  • Evidencia unikátnych hodnôt
  • Hľadanie spoločných prvkov
2. Slovníky (Dictionary)
Čo je slovník?
Slovník je dátová štruktúra typu kľúč : hodnota.

Príklady párov:

meno → vek | produkt → cena | štát → hlavné mesto
Vlastnosti
  • Každý kľúč je jedinečný
  • Pristupujeme cez kľúč
  • Nepoužívajú sa indexy
  • Veľmi rýchle vyhľadávanie
Základné operácie
vek = {
    "Jakub": 18,
    "Adam":  20,
    "Janka": 17
}

print(vek["Adam"])   # 20

vek["Peter"] = 25   # Pridanie nového záznamu
vek["Jakub"] = 30   # Prepísanie existujúcej hodnoty

print("Adam" in vek)  # True / False
Prechádzanie slovníka
for kluc in vek:
    print(kluc, vek[kluc])
Metódy
print(vek.keys())
# dict_keys(['Jakub', 'Adam', 'Janka', 'Peter'])

print(vek.values())
# dict_values([30, 20, 17, 25])

print(vek.items())
# dict_items([('Jakub', 30), ('Adam', 20), ...])
Metóda get()
Výhoda: nevyhodí chybu ak kľúč neexistuje.

slovnik.get(key, volitelna_defaultna_hodnota)

Vráti hodnotu k danému kľúču. Ak kľúč neexistuje, vráti None alebo prednastavenú hodnotu. 
print(vek.get("Adam"))               # 20
print(vek.get("Marek"))              # None
print(vek.get("Marek", "Neexistuje"))  # Neexistuje
Odstránenie položky a triedenie
del vek["Adam"]       # Odstránenie položky
print(sorted(vek))   # Triedenie kľúčov
Kde sa používa?
  • Databázy
  • Prekladače
  • Konfigurácie programov
  • Evidencia užívateľov
  • Skladové systémy
3. Ntice (Tuple)
Čo je ntica?
Ntica (tuple) je podobná zoznamu.

Rozdiel: Ntica je nemeniteľná.

Po vytvorení nemôžeme:
  • Pridávať prvky
  • Mazať prvky
  • Meniť hodnoty

Výhoda: rýchlejšia, bezpečnejšia, vhodná pre konštantné údaje.
Základné operácie
t = (1,2,3,4)

print(t[0])      # Dá sa indexovať
print(len(t))    # Dĺžka ntice

for prvok in t:
    print(prvok)
Operácie a kontrola výskytu
a = (1,2)
b = (3,4)

# Jediná možnosť ako pridať prvky je sčítať dve ntice
print(a + b)    # (1, 2, 3, 4)
print(a * 3)    # (1, 2, 1, 2, 1, 2)
print(2 in a)   # True / False
Rozbaľovanie ntice
Takto si do premennej vieme zadefinovať každý prvok v tuple: 
osoba = ("Jakub", 18, "Bratislava")

meno, vek, mesto = osoba

print(meno)   # Jakub
print(vek)    # 18
print(mesto)  # Bratislava
Rezy (Slices)
Syntax: ntica[od:po] — index „po" je vylúčený. Voliteľné tretie číslo `:2` vymaže každý druhý prvok v danom rozmedzí indexov. 
print(osoba[0:2])   # ('Jakub', 18)
Kde sa používa?
  • Súradnice bodov
  • Dátumy
  • RGB farby
  • Údaje ktoré sa nemajú meniť
4. Výnimky a Chybové Hlášky
Čo sú výnimky?
Výnimky (Exceptions) sa používajú na ošetrenie chýb počas behu programu.

Ak by sme ich nepoužili, program by sa ukončil pri prvej chybe.
Základná syntax
try:
    x = int(input("Zadaj cislo: "))
    print(x)
except ValueError:
    print("Nezadal si cele cislo")
Najčastejšie výnimky
  • ValueError — zlý formát hodnoty
  • IndexError — index mimo rozsahu
  • TypeError — nesprávny dátový typ
  • ZeroDivisionError — delenie nulou
  • FileNotFoundError — súbor neexistuje
  • AttributeError — objekt nemá danú metódu
  • ImportError — nepodarilo sa importovať modul
Príklad – ZeroDivisionError
try:
    print(10 / 0)
except ZeroDivisionError:
    print("Neda sa delit nulou")
Viac výnimiek naraz
try:
    index = int(input("Index: "))
    zoz = ["a","b","c"]
    print(zoz[index])
except ValueError:
    print("Musis zadat cislo")
except IndexError:
    print("Index mimo rozsahu")
Univerzálna výnimka
try:
    ...
except Exception as chyba:
    print(chyba)
Prečo sa používajú?
  • Program nespadne
  • Lepšia komunikácia s užívateľom
  • Bezpečné spracovanie vstupov
  • Práca so súbormi a databázami
Krátke Zhrnutie na Skúšanie
Množina
  • Unikátne hodnoty
  • Bez indexov
  • add, remove, discard
  • Zjednotenie, prienik, rozdiel
Slovník
  • Kľúč : hodnota
  • Prístup cez kľúč
  • keys, values, items, get
Ntica
  • Nemenný zoznam
  • Rýchlejšia a bezpečnejšia
  • Používa sa pre konštantné dáta
Výnimky
  • Ošetrujú chyby programu
  • try, except
  • ValueError, IndexError, TypeError, ZeroDivisionError
